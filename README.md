# 🤖 EcomDeal4U - Telegram Affiliate Bot

A feature-rich Telegram Affiliate Bot built with Python. The bot helps users discover deals, search products, save wishlists, use coupons, and receive updates. It also includes an admin panel for managing products and broadcasts.

---

## ✨ Features

### User Features
- Product Categories
- Search Products
- Latest Deals
- Sale Products
- Wishlist
- Coupon System
- Referral System
- FAQ
- Subscribe / Unsubscribe

### Admin Features
- Add Products
- Remove Products
- Broadcast Messages
- User Statistics
- Product Management

---

## 🛠 Tech Stack

- Python
- python-telegram-bot
- SQLite
- Supabase
- Railway
- GitHub

---

## 🔒 Security

- Bot Token stored securely using Environment Variables
- Sensitive credentials are not pushed to GitHub
- Production deployment configured for Railway

---

## 🚀 Deployment

Hosted on Railway with automatic deployment from GitHub.
